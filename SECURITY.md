# Security policy

## Reporting a vulnerability

Please report a vulnerability in durable-cache privately, through
[GitHub private vulnerability reporting](https://github.com/lmalheiro/durable-cache/security/advisories/new),
and not in a public issue. Say which version or commit you looked at, what an
attacker can achieve, and how to reproduce it.

You will get an answer as soon as possible, and credit in the published
advisory unless you prefer otherwise.

## Supported versions

Before 1.0, fixes go into the latest release only.

## Scope

The crate in `durable-cache/` is what this policy covers. The example in
`examples/` and the test infrastructure in `test/` are not meant to be
deployed, though reports about them are welcome too.

A vulnerability in Pingora® itself belongs to the Pingora project: see
[its security policy](https://github.com/cloudflare/pingora/security/policy).
